# 腾讯地图 Key（用于「杭州国宝地图」的地图底图与场馆定位）
#
# 用法：把 Key 直接写在下面这行（不要写「KEY=」前缀，就写 Key 本身）。
# 构建脚本会读取本文件里第一个非注释行。也可以改用环境变量 TMAP_KEY。
#
# 怎么申请（免费，官方原话：「目前Key申请完全免费，基础功能使用免费，且没有调用次数限制」）：
#   1. 打开 https://lbs.qq.com/ ，用 QQ 账号登录
#   2. 控制台 → 应用管理 → 我的应用 → 创建应用 → 添加 Key
#   3. JavaScript API GL 不需要勾选任何产品，直接创建即可（一个账号最多 5 个 Key）
#   4. 把生成的 Key 粘到下面
#
# 填好后这一行长这样（32 位，短横线分段）：
#   OB4BZ-D4W3U-B7VVO-4PJWW-6TKDJ-WPB77
#
# 注意：Key 是给自己本地用的，别提交到公开仓库。
#
# 留空也照样能用——底图和标记会正常显示，
# 但场馆自动定位会失败并弹一次「鉴权失败」，届时回落到备用坐标。
